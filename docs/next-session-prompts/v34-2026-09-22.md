## Job 5 — what is left on the CPU/GPU side, and it is small

- **`kernel_consts.py:39` is explained, 2026-09-22 (§9.33) — attribution artifact, not a lever.** The
  store-blocked time it shows is `expert_store.get_many()`'s own wait, mis-pinned to a rare LRU-cache-miss
  `mx.eval` that happens to be the next one to fire after the block ends; the profiler charges the gap since
  the last eval to whoever's eval ends it, not to whoever caused it. The 0.5 calls/token is cache warm-up (a
  few dozen misses total per session) amortized over a short 48-token measurement window, not a recurring
  cost. Nothing to fix; closed.
- The 3.48 ms between the FP8 GEMV kernel and `mx.sum` over its own bytes (§7.1.10). Still open.
- **The `w1`/`w3` fusion in the shared expert shipped, 2026-09-22, after one crash, one fix, and one live
  confirmation.** First version crashed Hamed's live session on the first decode step —
  `ValueError: [eval] Attempting to eval an array during function transformations like compile or vmap is
  not allowed` — because it called `mx.eval` inside `_compiled_moe_block`'s `mx.compile`d trace, which the
  shipped 2-bit affine bank always goes through; no unit test had called it that way. Fixed by moving the
  `w1`/`w3` concatenation into eager Python before the compiled call. Tried again live: clean, no crash, a
  642-token story and a 1,744-token Objective-C turn both read correct, speed near the shipped baseline (as
  expected — 0.4 ms/token was never going to show up in a live read). With the crash resolved and no further
  live signal possible by design, Hamed asked to flip the default and drop the kill switch in the same
  change. **`CACHALOT_FUSED_SHARED_EXPERT` no longer exists — the fused path is unconditional now.** The
  shared expert issues two GEMVs per layer instead of three on every decode call. `shared_expert_forward`
  (two-GEMV) stays only for `moe_prefill_grouped.py`'s separate, never-fused prefill fallback.
  `tests/test_shared_expert_fused.py` covers both the arithmetic (bit-identical) and the calling convention
  (a test that invokes the fused path from inside an actual `mx.compile`, reproducing the crash shape, plus
  one pinning that `mx.eval` inside a trace still raises if the bug is reintroduced) — 238/238 project tests
  pass. §9.27 (HANDOFF) has the full account, including the same real-bank warmup-plus-eight-tokens check run
  a third time after the switch was removed, same 8 token ids. Nothing left to do here.
